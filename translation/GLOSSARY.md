# 표기·번역 원칙

- 게임명: **광신화 파르테나의 거울**. `빛의 신화`, 후속작명인 `신 광신화`로 바꾸지 않습니다.
- 고유명: 파르테나, 엔젤랜드. 핵심 장비는 신기로 표기합니다.
- 시스템 안내는 존댓말, 신전의 대사는 위엄 있는 말투, 상점은 인물별 말투를 유지합니다.
- 버튼 이름 `START`, `SELECT`, `L`, `R`, `A`, `B`와 `1P`, `2P`는 입력 장치 표기로 유지합니다.
- 원래 영문 그래픽은 이번 작업 범위에서 제외합니다.

## 편집 제한

게임 문구는 18개 글리프 뱅크를 사용합니다. 한 뱅크에서 서로 다른 한글 음절을 과도하게 늘리면 슬롯 제한에 걸립니다.
줄 수·길이·문장부호는 빌더가 지원하는 범위 안에서 수정하고 전체 빌드로 확인하세요.

공통 메뉴는 30×20 글자 좌표를 사용합니다. `wrapper_ko.py`의 각 항목은 `(x, y, 문자열)`입니다.
예/아니요 및 1P/2P/취소는 선택 강조 제어 코드가 있어서 `tools/build_text_v3.py`에서 별도로 구성합니다.
해당 선택지 문구를 바꿀 때는 이 특수 처리도 함께 수정해야 합니다.
