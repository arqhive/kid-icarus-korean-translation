# 광신화 파르테나의 거울 한글 패치 v0.1

2026-09-29 · 첫 배포 버전 · 로컬 릴리즈

타이틀, 게임 메뉴·대사·엔딩, 패미컴 미니 공통 일본어 메시지 47개를 한글화했습니다.
폰트·로고의 세로 흔들림 수정이 포함되어 있습니다. 이전 내부 개발판 v3과 ROM 내용은 같습니다.

## 배포물

- `release/Palthena_KO_v0.1.ips`: 일본판 원본에 적용하는 IPS.
- `release/Palthena_KO_v0.1_Patch.zip`: IPS, 설명서, 확인값, Python 적용 도구, 라이선스.
- `release/manifest.json`: 원본·결과 ROM 및 패치의 확인값.

ROM은 포함하지 않습니다. ZIP은 `python tools/make_patch.py`로 생성하며 Git에는 포함하지 않습니다.
적용 방법과 ROM 확인값은 [README](../../README.md)를 참고하세요.

## 검증

- 원본 ROM에서 새 작업 폴더로 전체 빌드 재현, 이전 완성본과 SHA-256 일치.
- IPS 적용 결과와 빌드 ROM의 바이트 일치.
- 공통 번역 메시지 47개의 글리프 참조·좌표 및 가나 참조 부재 확인.
- mGBA 새 부팅, L+R 메뉴, 계속하기, 처음부터 동작 확인.
- 메뉴 글자 영역 120프레임 변화 없음, 타이틀은 공통 메뉴 추가 전 빌드와 픽셀 일치.

실제 GBA와 전체 구간 플레이, 모든 통신·저장 오류, 절전 해제는 미검증입니다.
이전 강제 저장 상태 대신 새로 부팅해서 사용하세요. 원래 영문 그래픽과 영문·숫자 이름 입력은 유지했습니다.
