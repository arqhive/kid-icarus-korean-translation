게임보이 어드밴스 「패미컴 미니 광신화 파르테나의 거울」 일본판 한글 패치의 최종판입니다. 일본어 원문을 기준으로 번역했습니다.

**수정하지 않은 원본 일본판 ROM용 IPS 패치입니다.**

## 변경 사항

- 상점에 들어갈 때, 물건을 사거나 값을 깎을 때, 점수 화면이 뜰 때 화면이 깜빡이거나 한 프레임 밀리던 문제를 고쳤습니다.
- 상태창을 열고 닫을 때 글자가 잠깐 뒤틀리던 문제를 고쳤습니다.
- 점수 계산 중에 보스방 화면이 비치던 문제를 고쳤습니다.
- 요새 표시줄의 "구간 / 보스"를 한 칸 높이의 작은 한글로 원본처럼 위아래로 맞췄습니다.
- 체력이 오를 때의 대사를 "체력 UP!"으로 바꾸고, 상점 인사와 암시장 외상 대사를 다듬었습니다.
- 타이틀의 `PUSH START BUTTON.`을 원래 영문으로 되돌렸습니다.
